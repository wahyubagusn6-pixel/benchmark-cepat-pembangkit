# Benchmark Cepat Kinerja Pembangkit

Prototipe Final Project MBCL Cohort 3 (Claude for Non-Tech Professional) oleh Wahyu Bagus Nugroho.

Tempel data pack dua perusahaan pembangkit (contoh: GPSC vs B.Grimm Power, Jan–Jun 2025 dan 2026). Halaman ini menghitung rasio setara dengan rumus tetap, menunjukkan rumus dan sumber setiap angka, dan menandai beda definisi yang perlu diputuskan analis.

- Satu file statis: `index.html` (tanpa build, tanpa server).
- Deploy: impor repositori ini di Vercel, pilih Framework Preset "Other", lalu Deploy.
